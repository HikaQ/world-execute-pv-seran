|---|---|---|
| 独立依赖安装 | 通过 | 发布目录中使用 npm ci；运行时不借用原工程的 node_modules |
| JS 语法、JSON 与文件排除检查 | 通过 | 公开源码树；未发现所列密钥模式、本机用户目录与聊天链接 |

抽样详情在 [validation-smoke.json](validation-smoke.json)。实际检查生成的图片、视频与安装依赖位于被忽略的 output/、node_modules/，不进入源码发布包。

边界：没有重新渲染整部 V24，没有进行全片逐像素比对，也没有在 Linux/macOS 上验证。占位图使部分画面与成片不同；依赖系统韩文字体的倒数镜头，在缺少相应字体的系统上可能需要补充合法字体。NVENC 可选参数保留，但这次源码整理仅验证了 CPU 编码。

当前测试说明发布版的入口和主要渲染路径能运行，不表示所有外部素材已公开，或每一帧已获得新的视觉确认。
